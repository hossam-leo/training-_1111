# Ethics, privacy, and licensing

Use only consented mock exams, public datasets with compatible licenses, or synthetic media. The browser must show a persistent recording indicator and request camera/microphone consent. Do not use this system for covert capture, minors, or unattended high-impact decisions. Automated flags are triage signals and require a human reviewer.

The repository stores no real recordings. Configure retention and deletion for any deployment, isolate biometric templates from event data, encrypt production storage, and obtain institutional/legal review. Heavy model weights are not bundled; each adapter must record code and weight licenses before production use.
